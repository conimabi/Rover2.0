# Rover2.0
没事逛二手市场时发现Brookstone 2.0小车 ，原厂的Rover2.0 app无法适配现在的手机和windows设备,在网上找到之前某位大佬改的安卓版本，但由于过于年久且并未适配后续的安卓8以后的设备也无法使用
为了能玩上使用deepseek v4 flash帮我修改apk适配安卓8以上的设备并且进行汉化，并稍微修改下页面样式。已在Redmi note 12turbo 上实验成功安卓15 澎湃os3.0.5.0上使用目前没发现有大问题。 
在搜索软件时发现了前几年GitHub上有几位大佬改出电脑版本，但是使用Linux系统python版本2.6使用的；后续借鉴这个版本并混合安卓软件整合出此windows版本，建议安卓python3.13.7版本使用，或者使用小白包里面进行安装使用，适配了手柄和键盘使用；但是语音和对话功能可能是我设备问题，车收音有很大是噪声；键盘使用wsad控制方向，上下控制摄像头上下，1~4分别对应车等，红外，麦，对话功能；
手柄我以使用盖世小鸡-启明星使用2.4G适配器使用成功.
（手头设备只适配了履带的Brookstone 2.0，对应4轮的并未去适配；你可把整个项目丢给Ai进行分析修改）
